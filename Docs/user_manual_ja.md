# Folder Cleaner ユーザーガイド

**Folder Cleaner** は、指定したフォルダ内にあるテクスチャアセットの中から、プロジェクト内の特定のフォルダ（使用元フォルダ）にあるアセットから使用（参照）されていないテクスチャを検出・削除する Unity エディタ拡張ツールです。

---

## 1. 起動方法

Unity エディタの上部メニューバーから、以下を選択します。
- **dennokoworks** ＞ **Folder Cleaner**

起動すると、UI Toolkit（dennokoworks フローティングデザイン）に準拠した専用ウィンドウが表示されます。

---

## 2. ヘッダー機能

- **バージョン表示・更新チェック**:
  - ウィンドウタイトル横に現行バージョン（例: `v1.0.0`）が表示されます。起動時に自動で最新版をチェックし、アップデートがある場合は緑色で更新版数が表示され、最新版の取得に失敗した場合はオレンジ色で「最新版を取得できません」と表示されます。
  - 右側の `↻` ボタンをクリックすると、いつでも手動でアップデートを再確認できます。
- **言語切替 ([EN] / [JA])**:
  - 右上の言語ボタンをクリックすることで、UI の表示言語を日本語と英語で即座に切り替えることができます（設定は自動保存されます）。

---

## 3. 設定項目

ウィンドウは「整理するテクスチャ」「使用判定（保護基準）」「削除オプション」「スキャン結果」の各セクションで構成されています。

### 整理するテクスチャ（削除対象）
| 設定項目 | 説明 |
| :--- | :--- |
| **整理するフォルダ** | 未使用テクスチャを検出・削除したいフォルダを指定します（サブフォルダ内のテクスチャも検索対象になります）。 |
| **保護するサブフォルダ** | 「整理するフォルダ」の中で、削除候補に含めたくない（保護したい）サブフォルダを指定します。「＋ 保護するサブフォルダを追加」で複数指定可能です。 |

### 使用判定（保護基準）
| 設定項目 | 説明 |
| :--- | :--- |
| **使用元フォルダ (マテリアル等)** | テクスチャが使用されているかを判定するためのフォルダ（例: `Assets/Materials` や `Assets/Prefabs` など）を指定します。ここにあるアセットが使用しているテクスチャは保護（保持）されます。「＋ 使用元フォルダを追加」で複数指定可能です。 |
| **判定から除外するサブフォルダ** | 使用判定の検索から除外したいフォルダを指定します（自己参照による誤判定防止など）。「＋ 判定から除外するサブフォルダを追加」で複数指定可能です。 |

> [!NOTE] **自動除外機能について**
> 「整理するフォルダ」が「使用元フォルダ」のいずれかのサブフォルダである場合、自分自身の中にあるアセットからの参照によって「使用中」と誤判定されてしまうのを防ぐため、自動的に「判定から除外するサブフォルダ」へ追加されます。

### 削除オプション
どちらのモードが選択されているかは、アクティブなボタンの**青枠線ハイライト**および直下の説明文で確認できます。

| モード | 説明 |
| :--- | :--- |
| **ゴミ箱へ移動（推奨）** | 削除したテクスチャは OS のゴミ箱へ移動します（後から復元可能です）。 |
| **完全に削除** | 削除したテクスチャはプロジェクトから完全に削除されます（復元できません）。 |

---

## 4. 使用手順

### ステップ 1: フォルダの指定
1. 「整理するフォルダ」に対象フォルダをドラッグ＆ドロップまたはアセットピッカーから指定します。
2. 「使用元フォルダ」にテクスチャを使っているアセットが存在するフォルダを指定します。
3. 必要に応じて「保護するサブフォルダ」や「判定から除外するサブフォルダ」を設定します。

### ステップ 2: スキャンの実行
1. ウィンドウ下部の **「スキャン」** ボタンをクリックします。
2. スキャンが完了すると、「スキャン結果」セクションに未参照テクスチャの一覧と件数が表示されます。
3. 検出された各テクスチャの右側にある **「選択」** ボタンをクリックすると、Project ウィンドウ上で該当アセットがハイライト（Ping）され、確認することができます。
4. 削除したくないファイルがある場合は、左側のチェックボックスを外すことで除外できます（「すべて選択」「すべて解除」も利用可能）。

### ステップ 3: 削除の実行
1. 削除対象の選択を確認したら、ウィンドウ下部の **「削除を実行」** ボタンをクリックします。
2. 確認ダイアログが表示されるので、**「実行」** をクリックすると削除処理（またはゴミ箱への移動）が行われます。

---

## 5. 注意事項

> [!WARNING] **参照範囲の制限について**
> このツールは、**「使用元フォルダ」で指定されたフォルダ配下のアセット** からの参照のみをチェックします。
> もし「使用元フォルダ」に指定していないフォルダ（例: 他のパッケージ内、または指定から漏れたフォルダ）のアセットが該当テクスチャを参照している場合でも、このツールは「未参照」と判定し、削除対象にしてしまいます。
> スキャン結果の削除を実行する前に、本当に他の場所で使用されていないか十分にご確認ください。
